# Measurement Plan

The goal is to build evidence over time rather than claim impact before it is measured.

## Operational metrics

- Daily upload compliance by location
- Number of files submitted per location
- Latest upload time
- Days requiring manual follow-up
- Estimated time spent on manual checking
- Percentage of submitted footage that is usable

## Content metrics

- Posting consistency
- Reach / views
- Shares / saves
- Comments / DMs
- Profile visits / link clicks
- Best and weakest content formats

## Business metrics when trackable

- Inquiries
- Trial requests
- Bookings
- Google Business activity
- Reviews
- Conversion by location or campaign

## Portfolio evidence

For each meaningful improvement, document:

```text
Problem
→ Decision
→ Implementation
→ Result
→ Lesson
```

Quantified claims will only be added after a reliable baseline and comparison period exist.
